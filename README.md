## Структура

```
react-kurs/
├── zayavki/           доска заявок по главам справочника (создаётся в главе 1.1)
├── avtomatizaciya/    Docker: n8n, PocketBase, Ollama (создаётся на странице «Автоматизация»)
├── projects/          проекты модулей: папка pN-<вариант> на проект
├── lectures/          конспекты глав (ведёт преподаватель)
├── materials/         файлы с занятий (ведёт преподаватель)
└── docs/              правила сдачи и обновления (ведёт преподаватель)
```

## Как запустить

```bash
git clone https://github.com/<логин>/react-kurs.git
cd react-kurs/zayavki
npm install
npm run dev
```
