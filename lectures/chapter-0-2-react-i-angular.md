# Глава 0.2. React и Angular в 2026 году

Глава справочника: [0.2 React и Angular в 2026 году](https://maximbytecamp.github.io/angular_react_makarov/temy/02-react-i-angular/index.html)

## О чём глава

В этой главе разобрано, кто разрабатывает React и Angular, как часто выходят их версии и сколько разработчиков ими пользуется. Одна и та же небольшая задача — поиск по списку — записана на обоих фреймворках, и по ней видны основные различия в работе. Отдельный раздел объясняет, почему инструменты ИИ по-разному относятся к двум фреймворкам и как это влияет на выбор.

## Итог

React с 2026 года развивается под управлением React Foundation, Angular — командой Google по годовому графику с поддержкой каждой версии 24 месяца. По опросу Stack Overflow 2025 React используют 44,7% разработчиков, Angular — 18,2%; Angular чаще встречается в банках и корпоративных системах. На одной задаче видно, что модели у фреймворков общие — состояние, вычисляемые значения, разметка, ключи списка, — а запись разная: хуки и JSX в React, сигналы и шаблоны в Angular. Инструменты ИИ по умолчанию пишут React, а для Angular часто предлагают устаревший код; команда Angular отвечает на это инструментами для агентов.
