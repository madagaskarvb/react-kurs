# Глава 1.6. Формы и отправка данных

Глава справочника: [1.6 Формы и отправка данных](https://maximbytecamp.github.io/angular_react_makarov/temy/16-formy/index.html)

## О чём глава

В этой главе форма «Новая заявка» начинает работать. Сначала в данные заявки добавляется категория из выпадающего списка. Затем поля формы подключаются к состоянию React, и опыт показывает, что будет, если подключить их наполовину. После этого кнопка «Отправить заявку» добавляет заявку в начало списка и очищает форму. В конце форма проверяет, что важные поля заполнены, и показывает сообщение об ошибке.

## Итог

Текст полей формы хранят в состоянии: у управляемого поля `value` берёт значение из состояния, а `onChange` записывает в него каждое изменение. Поле с `value`, но без `onChange`, становится только для чтения. Отправку обрабатывают у самой формы через `onSubmit`; первой строкой обработчика вызывают `event.preventDefault()`, иначе браузер перезагрузит страницу. Данные формы передают родителю через prop-функцию, родитель добавляет номер и статус и строит новый массив `[created, ...requests]`. Перед отправкой обязательные поля проверяют с `trim()`; при ошибке записывают текст сообщения в состояние и выходят из обработчика через `return`. Доска заявок принимает новые заявки из формы, но хранит их только до перезагрузки страницы.

## Шпаргалка

| Что | Как |
|---|---|
| Состояние поля | `const [title, setTitle] = useState('')` |
| Управляемое поле | `<input value={title} onChange={(event) => setTitle(event.target.value)} />` |
| Список | `<select value={category} onChange={…}>` |
| Отправка | `<form onSubmit={handleSubmit}>` |
| Без перезагрузки | `event.preventDefault()` |
| Пустое поле | `title.trim() === ''` |
| Добавить в начало | `setRequests([created, ...requests])` |
| Уникальный номер | `Date.now()` |
