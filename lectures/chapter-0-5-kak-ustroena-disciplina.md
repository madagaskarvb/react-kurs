# Глава 0.5. Как устроена дисциплина

Глава справочника: [0.5 Как устроена дисциплина](https://maximbytecamp.github.io/angular_react_makarov/temy/05-kak-ustroena-disciplina/index.html)

## О чём глава

В этой главе описано, чему учит дисциплина и как она построена. Каждый модуль состоит из трёх частей: теория React, нужная для проекта, небольшой проект на этой теории и автоматизация вокруг проекта: бот, языковая модель, работа по расписанию. Перечислены модули с проектами, бесплатные инструменты, на которых всё работает, правила работы с ИИ и список проверки кода. Глава заканчивается заданием к модулю 0.

## Итог

Дисциплина учит понимать, как устроено веб-приложение, собирать небольшое приложение на React и связывать его с сервисами и автоматизациями. Основной фреймворк — React, Angular изучается одной обзорной парой. Каждый модуль состоит из теории, нужной для проекта, проекта на React и автоматизации к нему: доска заявок с ботом, затем с базой и ИИ-диспетчером, мониторинг сайтов по расписанию, дайджест новостей, сделанный с ИИ-агентом, и свой проект. Все инструменты бесплатны, часть из них работает на компьютере студента. Каждое задание помечено режимом работы с ИИ, а любую строку сданной работы студент объясняет на защите.
