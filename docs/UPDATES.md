# Как приходят новые материалы

Преподаватель дополняет шаблон курса: конспекты глав, проекты модулей, файлы занятий.
Каждый день в 06:00 по Москве GitHub переносит их в ваш репозиторий.
Это делает файл [`.github/workflows/update-materials.yml`](../.github/workflows/update-materials.yml).
В истории коммитов перенос виден как коммит `materials: обновление из шаблона курса`
от `github-actions[bot]`.

## Что меняется и что нет

| Файлы | Что происходит при обновлении |
|---|---|
| `lectures/`, `materials/`, `docs/` | заменяются версией преподавателя |
| `README.md` в папке `projects/` | заменяется: в нём таблица выданных проектов |
| новые файлы шаблона | добавляются, если их у вас нет |
| ваши `zayavki/`, `avtomatizaciya/`, проекты, `README.md` в корне | не меняются |
| удалённые вами файлы шаблона | возвращаются: удалять файлы шаблона не нужно |

Файлы преподавателя не редактируйте: при следующем обновлении правка пропадёт.

## Забрать обновление сразу

1. Откройте свой репозиторий на GitHub, вкладка **Actions**.
2. Слева выберите **Обновление материалов курса**.
3. Нажмите **Run workflow → Run workflow**.
4. Через минуту в списке появится запуск с зелёной галочкой. В нём раздел
   «Обновление материалов курса» перечисляет новые файлы.

## Забрать обновление в VS Code

Обновление попадает только на GitHub. Чтобы новые файлы появились на компьютере,
перед началом работы нажмите **Sync Changes** (кнопка ⟳ в строке состояния внизу).
Если VS Code пишет про расходящиеся ветки (`divergent branches`), один раз выполните в терминале

```bash
git config pull.rebase false
```

и снова нажмите **Sync Changes**.

Подробно со снимками: [работа с репозиторием](https://algorthimization-course-vvodnoe.vercel.app/angular-react/repozitoriy/index.html#s10).
